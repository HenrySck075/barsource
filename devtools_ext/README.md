# barsource_devtools

DevTools extension UI for BarSource.

## Features

- **Hot Reload** button wired to `ext.barsource.reassemble`
- **Widgets Tree** inspector sourced from `ext.barsource.widgetTree`
- **Runtime** tab showing render status from `ext.barsource.status`

## Required BarSource service extensions

- `ext.barsource.reassemble`
- `ext.barsource.widgetTree`
- `ext.barsource.status`
